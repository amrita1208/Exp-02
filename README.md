# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
To study and prepare the Software Requirements Specification (SRS) for a Library Management System and represent the system using UML diagrams.

# SRS (Procedure):
1.Identify the users of the Library Management System (Librarian, Student/Member, Administrator).
2.Gather the functional and non-functional requirements.
3.Define the system scope and objectives.
4.Prepare the Software Requirements Specification (SRS) document.
5.Develop the required UML diagrams based on the SRS.
6.Verify that the diagrams accurately represent the system requirements.
